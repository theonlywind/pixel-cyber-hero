# 老師後台（Google Apps Script + Google Sheet）

學生玩遊戲時，會自動將「班別學號、關卡、星數」上報去你嘅 Google Sheet；老師開後台網頁就睇到每個學生嘅完成紀錄。免費，唔使自己部伺服器。

## 設定（約 10 分鐘，只做一次）

1. 開一個新嘅 **Google Sheet**（名隨便，例如「網絡安全小勇者紀錄」）。
2. 選單 **擴充功能 → Apps Script**。
3. 將 `Code.gs` 全部內容貼入編輯器（取代預設嘅 `Code.gs`）。
4. 左邊 **＋ → HTML**，檔名輸入 `admin`，將 `admin.html` 全部內容貼入。
5. 設定老師密碼：左邊 **專案設定（齒輪）→ 指令碼屬性 → 新增**，名稱 `ADMIN_PASS`，值係你自己嘅密碼。
6. 右上 **部署 → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生唔使登入 Google 先上報得）
   - 按部署，授權後會得到一條 `https://script.google.com/macros/s/…/exec` 網址。
7. 將呢條網址貼入遊戲嘅 `config.js`：
   ```js
   window.REPORT_URL = 'https://script.google.com/macros/s/…/exec';
   ```
   然後 push 到 GitHub（`git add -A && git commit -m "Set report URL" && git push`）。
8. 老師睇紀錄：直接開同一條 `/exec` 網址，輸入 `ADMIN_PASS`。

> 之後如果改咗 `Code.gs` 或 `admin.html`，要 **部署 → 管理部署作業 → 編輯 → 新版本** 先會生效。

## 上報咗啲乜

| 事件 | 時機 | 內容 |
|---|---|---|
| `start` | 學生按「開始冒險」 | 班別學號、年級 |
| `level` | 過關 | 關卡、星數、答錯次數 |
| `fail` | HP 用完 | 關卡 |
| `boss` | 黑客熊挑戰結束 | 是否通過、答對題數 |
| `cert` | 第一次領證書 | 證書編號 |

- 資料寫入 Sheet 嘅 `records` 工作表，每個事件一行，老師亦可以直接用 Sheet 篩選、做圖表。
- **唔收集真實姓名**。遊戲入面輸入嘅名只存喺學生自己嘅瀏覽器。學生要輸入班別學號（如 `3A05`，2–8 個英數字）；留空就唔上報。

## 私隱同限制（請留意）

- 資料存喺你嘅 Google 帳戶，請按學校政策處理，並建議先向家長／學校說明收集範圍。
- 上報網址要「所有人」可存取，所以**理論上任何人知道網址都可以送假紀錄**。後台只接受格式正確嘅資料，但冇辦法分真假；如果有人搗亂，可以喺 Sheet 刪行，或者重新部署一條新網址。
- 遊戲進度仍然存喺**每部裝置嘅瀏覽器**。如果幾個學生共用一部 iPad，本機進度會混埋；後台紀錄就係按各自輸入嘅學號分開。想避免，叫學生用「重新開始」或每人用自己裝置。
- 上報失敗（冇網絡）會排隊，下次開遊戲或恢復網絡時自動補送；但如果 Google 收到之後拒絕，遊戲睇唔到結果（`no-cors` 限制）。
- `config.js` 留空（預設）嘅話，遊戲完全唔上報，標題畫面亦唔會出現「班別學號」。
